# Robin Kapka
### Plugins et scripts Adobe sur mesure
**Creative Tools by Robin Kapka**

Je conçois des outils qui simplifient le travail dans les applications Adobe : automatisation, adaptation de workflows et résolution de problèmes de compatibilité, pour les entreprises comme pour les particuliers.

## Afri-Plugin
Une suite d’outils pensés pour les besoins concrets des créatifs : **Afri Logo**, **Afri Down**, **Afri Font** et **Afri Connect Aurora**.

## À découvrir : Afri Connect Aurora
Une passerelle pour utiliser Aurora HDR depuis Photoshop récent sur Mac Apple Silicon : ouverture dans Aurora, Looks et filtres d’origine, puis retour automatique du résultat dans un nouvel objet dynamique Photoshop.

**[Découvrir l’outil et le télécharger gratuitement](https://github.com/afriction/afri-connect-aurora)**
